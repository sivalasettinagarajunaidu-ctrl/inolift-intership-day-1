Project Overview

The Student Registration System is a Flask web application designed to collect, display, and manage student information through a professional web interface.

Features

Template rendering, page navigation, styled forms, student tables, and responsive layouts.

Team Information

Developed by the student project team as part of the Flask frontend development task.
